# 사무용품 상시 신청

사원은 필요할 때마다 품목 목록에서 사무용품을 신청하고, 기획팀은 분기 말에 카테고리별 주문서 엑셀을 버튼 한 번으로 받는 정적 웹앱입니다.

- 설치·빌드 없음: `index.html`, `style.css`, `app.js` 세 파일이 전부
- 외부 서버·데이터베이스·라이브러리 없음: 데이터는 브라우저 `localStorage`에 저장
- 주문서 엑셀(.xlsx)도 브라우저 안에서 직접 생성 (A4 가로, 1페이지 너비 맞춤, 제목 행 반복 인쇄)

## 바로 열기

`index.html`을 크롬으로 열면 됩니다.

## 화면

| 화면 | 주소 | 기능 |
| --- | --- | --- |
| 신청하기 | `index.html#apply` | 품목 검색·카테고리 필터, 기타 신청, 한도 경고, 내 신청 조회·수정·취소(3일 이내) |
| 관리자 | `index.html#admin` | 분기별 카테고리 합산, 신청자 펼치기, 한도 초과 표시, 기타 신청 승인·반려, 건별 취소, 분기 마감, 주문서 엑셀, 설정·품목 교체, 백업·복원 |

처음 관리자 화면에 들어가면 관리자 비밀번호를 만들도록 안내합니다.

## 꼭 알아 둘 점

`localStorage`는 **브라우저마다 따로** 저장됩니다. 그래서 지금 버전은 여러 사원이 각자 PC에서 신청한 내용을 관리자가 한 화면에서 모아 볼 수 없습니다. 한 PC에서 시연·테스트하거나 공용 PC 한 대로 신청받는 용도로 쓰고, 실제 100명이 쓰려면 저장 위치를 공유 저장소(예: 구글 시트 + Apps Script)로 바꿔야 합니다. 저장 코드는 `app.js`의 `Store` 객체 한 곳에 모아 두었습니다.

## GitHub · Vercel 배포

1. GitHub에 새 저장소를 만들고 세 파일(`index.html`, `style.css`, `app.js`)과 이 README를 올립니다.
2. Vercel에서 **Add New → Project → 해당 저장소 Import**를 누릅니다.
3. Framework Preset은 **Other**, Build Command와 Output Directory는 비워 두고 **Deploy**를 누릅니다.
